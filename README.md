# 🚀 AI Orchestration Studio | Autonomous Multi-Cloud & Media Engine

A high-performance, white-labeled **AI Orchestration Studio** providing a clean executive front-end for autonomous multi-cloud operations, generative 3D storytelling, FinOps data pipeline ingestion, and real-time Power BI streaming.

---

## 🌟 Key Capabilities

1. **🎬 3D Pixar / Disney Story Animation Studio:**
   - Autonomous pipeline producing Full HD 1080p 3D animated cinematic stories with neural voiceover dialogues and synchronized Indian classical music.
2. **📊 Multi-Cloud FinOps Data Engine:**
   - Automated ingestion of AWS Cost & Usage Reports (S3) and OCI Telemetry (Object Storage) normalized via FastMCP into Power BI REST Push datasets.
3. **🕵️ Cinematic FinOps Video Trailers:**
   - 60-second tech-noir mystery videos explaining complex multi-cloud spend variance and executive insights.
4. **☁️ Cloud Infrastructure Provisioning:**
   - Automated provisioning loops for OCI Always-Free Ampere ARM instances and AWS resources.

## 🚀 Deployment Options

### Option 1: GitHub Pages (Instant 1-Click Hosting)
1. In this repository, go to **Settings ➔ Pages**.
2. Under **Build and deployment ➔ Source**, select **Deploy from a branch**.
3. Choose Branch: `main`, Folder: `/ (root)` and click **Save**.
4. Your application will be live globally at `https://karnkeshav.github.io/ai-orchestration/`.

---

### Option 2: OCI Always-Free Compute Instance (24/7 Dedicated Server)
This repository includes a native **Dockerfile** and **docker-compose.yml** for instant deployment on an Oracle Cloud Always-Free VM:

```bash
# 1. Clone on your OCI Instance
git clone https://github.com/karnkeshav/ai-orchestration.git
cd ai-orchestration

# 2. Run with Docker Compose
docker compose up -d
```
Access your studio via your OCI Instance Public IP (`http://<YOUR_OCI_PUBLIC_IP>`).
